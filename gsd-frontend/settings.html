System Settings

Manage inventory thresholds, full-system backups, and controlled data reset.

Default Low-Stock Threshold

Set the default low-stock threshold (reorder point) used for new products and items without a custom per-item threshold. Products with a custom threshold set via Inventory Edit keep their override unless you apply the default to all products.

Items at or below this quantity show “Low Stock”

Data Backup & Recovery

Download a full snapshot of inventory, movement history, active user details, and reset-request records. Backups cover the entire system.

Full System Scope
Full system scope: The backup includes all inventory, transactions, users, and reset requests.

Danger Zone: Clear Data / System Wipe

Permanently erase all inventory items, transactions, and password-reset requests. User accounts are retained. This action cannot be undone.

High Risk System-Wide Wipe: Wiping Consolidated data will permanently erase all products, transactions, and request history across ALL branches. Admin credentials remain protected.

Confirm Data Wipe

This will permanently erase all inventory, movement history, and password-reset requests. User accounts remain. Type WIPE below to confirm.
